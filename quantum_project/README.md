# Quantum Project

Проект для почасовой отправки отчетов в ВКонтакте с результатами квантовых бенчмарков и ответами локальной языковой модели.

## Описание

Скрипт автоматически:
- Загружает локальную LLM модель (Qwen2-7B)
- Получает ответы на вопросы о квантовых вычислениях
- Запускает бенчмарк симуляции квантовых состояний
- Собирает информацию о системе (CPU, RAM, GPU)
- Формирует красивый отчет и публикует его в VK группу
- Повторяет процесс каждый час

## Установка

1. Установите зависимости:
```bash
pip install torch transformers requests psutil
```

2. Скачайте модель Qwen2-7B:
```bash
# Через huggingface-cli или вручную разместите в папке ./Qwen2-7B
```

3. Настройте параметры в `vk_hourly_report.py`:
   - `GROUP_SCREEN_NAME` - имя вашей группы VK
   - `ACCESS_TOKEN` - токен доступа VK API
   - `MODEL_PATH` - путь к модели
   - `INTERVAL_SECONDS` - интервал между постами (по умолчанию 3600 = 1 час)
   - `CHAT_PROMPT` - вопрос для языковой модели

## Запуск

```bash
python vk_hourly_report.py
```

## Пример отчета

Отчет включает:
- Дату и время публикации
- Информацию о системе (процессор, память, видеокарта)
- Диалог с локальной моделью (вопрос и ответ)
- Результаты бенчмарка суперпозиции квантовых состояний
- Сводку о преимуществах квантовых вычислений
- Хештеги для лучшего охвата

## Особенности

- **Безопасная печать**: Автоматическая обработка проблемных символов UTF-8
- **Обработка ошибок**: При ошибке в цикле выполнение продолжается
- **Адаптивный бенчмарк**: Автоматическая остановка при превышении лимита времени
- **Экономия ресурсов**: Модель загружается один раз при старте

## Примечание

Классическая симуляция квантовых состояний требует экспоненциально растущих ресурсов:
- 30 кубит ≈ 17 минут вычислений
- 40 кубит ≈ 12 дней вычислений

Это демонстрирует необходимость квантовых компьютеров для работы с большими пространствами состояний.
