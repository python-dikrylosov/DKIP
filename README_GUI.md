# TON Token Marketplace v3 - PyQt6 GUI Приложение

## 🚀 Описание

Асинхронное графическое приложение на **PyQt6** для анализа токенов TON Blockchain с использованием многоагентной ИИ системы.

## ✨ Особенности

- **Современный темный интерфейс** в стиле Fusion
- **Многоагентная ИИ система**:
  - 📊 MarketAnalyzer - анализ рынка и метрик токена
  - 🛡 RiskAdvisor - оценка рисков и выявление скамов
  - 💡 PersonalTrader - персонализированные рекомендации
- **Асинхронная архитектура** - анализ выполняется в отдельном потоке
- **SQLite база данных** - хранение истории анализов и профилей пользователей
- **Интеграция с TonAPI** - получение реальных данных о токенах
- **Поддержка мета-токена DKIP**

## 📋 Требования

- Python 3.8+
- PyQt6
- SQLite3 (встроен в Python)

## 🔧 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd <repository_directory>
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Настройте переменные окружения в `.env`:
```
TON_API_KEY=your_tonapi_key_here
DATABASE_URL=sqlite:///database.db
```

## 🚀 Запуск приложения

```bash
python gui_app.py
```

## 🏗 Архитектура

### Компоненты

#### `gui_app.py`
Главное приложение PyQt6:
- `AsyncWorker` - поток для асинхронного выполнения задач
- `TokenInfoCard` - карточка информации о токене
- `RiskMeter` - индикатор риска с прогресс-баром

Многоагентная ИИ система:
- `MarketAnalyzer` - анализ рыночных данных
- `RiskAdvisor` - оценка рисков
- `PersonalTrader` - персональные рекомендации

#### `ton_integration.py`
Интеграция с TON Blockchain:
- `TonAPIWrapper` - обертка для TonAPI

#### `database.py`
База данных пользователей:

## 📊 Функциональность

### Анализ токена

При анализе токена выполняются:
1. Получение информации о токене из TonAPI
2. Анализ распределения держателей
3. Оценка ликвидности и объема торгов
4. Расчет скоринга риска (0-100)
5. Генерация персональной рекомендации

### Оценка рисков

Факторы риска:
- Концентрация держателей (>80% - высокий риск)
- Ликвидность (<1000 TON - низкая ликвидность)
- Объем торгов (отсутствие торгов - риск)
- Количество держателей (<100 - мало держателей)

Уровни риска:
- **НИЗКИЙ** (0-29): Относительно безопасен
- **СРЕДНИЙ** (30-49): Умеренный риск
- **ВЫСОКИЙ** (50-69): Высокий риск
- **КРИТИЧЕСКИЙ** (70-100): Не рекомендуется

### Персонализация

Рекомендации зависят от профиля риска пользователя:
- **Низкий**: Только безопасные токены
- **Средний**: Умеренный риск допустим
- **Высокий**: Агрессивные стратегии

## 💾 База данных
