## 🔥 Автономная система нового поколения

**Quantum AI Marketplace** — это децентрализованная платформа, объединяющая **квантовые вычисления**, **искусственный интеллект**, **блокчейн** и **полную автоматизацию** в единую экосистему для трейдинга, аналитики и генерации контента.

Система работает 24/7, ежечасно проводя квантовые бенчмарки, генерируя ИИ-прогнозы, фиксируя результаты в блокчейне и публикуя отчеты в социальных сетях (VK, Telegram).

---

## ⚛️ Ключевые возможности

### Квантовое ядро
- Адаптивные бенчмарки суперпозиции (10–30+ кубитов)
- Оценка производительности классических систем для квантовых задач
- Динамическое ограничение по времени и памяти

### 🤖 Мультиагентный ИИ
- **Market Analyzer**: анализ рыночных данных и трендов
- **Risk Advisor**: оценка рисков и волатильности
- **Personal Trader**: генерация торговых сигналов
- Локальная поддержка LLM (Qwen2, Llama, Mistral)

### ⛓️ Блокчейн-интеграция
- Неизменяемый лог всех операций (хэширование отчетов)
- Поддержка TON Blockchain для смарт-контрактов
- Прозрачная история всех прогнозов и сделок

### 🔄 Полная автоматизация
- Ежечасный цикл работы без вмешательства человека
- Авто-публикация отчетов в ВКонтакте и Telegram
- Мониторинг ресурсов (CPU, RAM, GPU)
- Обработка ошибок и авто-перезапуск

### Ежечасный рабочий цикл

1. **Квантовый бенчмарк** → Тестирование 10–30 кубитов, замеры времени
2. **Сбор метрик** → Информация о системе (CPU, RAM, GPU)
3. **ИИ-анализ** → Генерация прогнозов через локальную LLM
4. **Блокчейн-лог** → Хэширование отчета, запись транзакции
5. **Публикация** → Отчет в ВКонтакте + уведомление в Telegram
6. **Ожидание** → Пауза до следующего часа

## 🔧 Компоненты системы

### 1. QuantumCore (Квантовое ядро)
- Адаптивные квантовые бенчмарки суперпозиции
- Симуляция квантовых состояний (10–30+ кубитов)
- Оценка квантового преимущества
- Динамическое ограничение по времени и памяти

- **Market Analyzer**: анализ рыночных данных и трендов

- Логирование прогнозов в блокчейн (TON, Ethereum)
- Смарт-контракты для автоматизации сделок
- Неизменяемая история операций
- Хэширование отчетов для верификации

### 4. AutomationEngine (Автоматизация)
- Почасовая публикация отчетов в VK
- Уведомления в Telegram 24/7
- Мониторинг ресурсов системы (CPU, RAM, GPU)
- Обработка ошибок и авто-перезапуск

## 🚀 Быстрый старт

### Требования

- Python 3.9+
- CUDA-совместимая видеокарта (рекомендуется для LLM)
- 16+ GB RAM (для 7B моделей)
- Токены доступа: VK API, Telegram Bot API

### Установка зависимостей

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/quantum_ai_marketplace.git
cd quantum_ai_marketplace

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows

# Установка зависимостей
pip install -r requirements.txt
```

### Настройка

1. Создайте файл конфигурации:

```bash
cp config/.env.example config/.env
```

2. Отредактируйте `config/.env`, добавив свои ключи:

```ini
# VK API
VK_ACCESS_TOKEN=ваш_токен_vk
VK_GROUP_SCREEN_NAME=dikrylosov
VK_API_VERSION=5.131

# Telegram Bot
TG_BOT_TOKEN=ваш_токен_telegram
TG_CHAT_ID=ваш_chat_id

# Модель
MODEL_PATH=./models/Qwen2-7B
MODEL_MAX_TOKENS=256

# Интервал (в секундах, 3600 = 1 час)
REPORT_INTERVAL=3600

# Квантовые настройки
MAX_QUBITS=30
TIME_LIMIT=10.0
```

3. Скачайте модель (опционально):

```bash
# Скачайте Qwen2-7B или другую модель в папку models/
# Например, через Hugging Face:
# git lfs install
# git clone https://huggingface.co/Qwen/Qwen2-7B models/Qwen2-7B
```

### Запуск

```bash
# Основной режим (ежечасные отчеты 24/7)
python main.py

# Режим тестирования (один цикл без ожидания)
python main.py --test

# Режим только бенчмарка
python main.py --benchmark-only

# Режим только ИИ-диалога
python main.py --chat-only
```

Система запустится в режиме 24/7 с интервалом 1 час между циклами.

## ⚙️ Конфигурация

Основные настройки в `config/.env`:

```ini
# Интервал между циклами (1 час = 3600 секунд)
REPORT_INTERVAL=3600

# Путь к модели
MODEL_PATH=./models/Qwen2-7B

# Промпт для ИИ-анализа
CHAT_PROMPT="Кратко объясните преимущества квантовых компьютеров перед классическими."

# Квантовые настройки
MAX_QUBITS=30
TIME_LIMIT=10.0
```

Или программно в `main.py`:

```python
INTERVAL_SECONDS = 3600  # Интервал между циклами (1 час)
MODEL_PATH = "./models/Qwen2-7B"  # Путь к модели
CHAT_PROMPT = "Ваш промпт для анализа"
```

## 🔐 Безопасность

- **Не храните секреты в коде!** Используйте переменные окружения или `.env` файл
- Для production используйте менеджеры секретов (HashiCorp Vault, AWS Secrets Manager)
- Ограничьте доступ к приватным ключам блокчейна
- Не коммитьте `.env` файл в Git (добавлен в `.gitignore`)
