# 🚀 Quantum AI Marketplace

**Объединенная система: Квантовые вычисления + ИИ + Блокчейн + Автоматизация**

## 📋 Описание

Автономная платформа, которая объединяет четыре ключевые технологии в единую экосистему:

- **Квантовые вычисления** - бенчмарки и симуляция квантовых алгоритмов
- **Искусственный интеллект** - анализ данных и прогнозирование на основе LLM
- **Блокчейн** - неизменяемое логирование и смарт-контракты
- **Автоматизация** - почасовые отчеты в VK и Telegram 24/7

## 🔧 Компоненты

### 1. QuantumCore
- Адаптивные квантовые бенчмарки
- Симуляция квантовых состояний
- Оценка квантового преимущества

### 2. AIAgent
- Локальная языковая модель (Qwen2-7B)
- Генерация аналитических отчетов
- Прогнозирование трендов

### 3. BlockchainManager
- Логирование прогнозов в блокчейн
- Смарт-контракты для автоматизации
- Неизменяемая история операций

### 4. AutomationEngine
- Почасовая публикация в VK
- Уведомления в Telegram
- Мониторинг ресурсов системы

## 🚀 Быстрый старт

### Установка зависимостей

```bash
cd quantum_ai_marketplace
pip install -r requirements.txt
```

### Настройка

1. Создайте файл `.env` с вашими ключами:
```bash
VK_ACCESS_TOKEN=your_vk_token
TELEGRAM_BOT_TOKEN=your_telegram_token
TELEGRAM_CHAT_ID=your_chat_id
BLOCKCHAIN_PRIVATE_KEY=your_private_key
```

2. Скачайте модель (опционально):
```bash
# Скачайте Qwen2-7B в папку models/
```

### Запуск

```bash
python main.py
```

Система запустится в режиме 24/7 с интервалом 1 час между циклами.

## 🔐 Безопасность

- **Не храните секреты в коде!** Используйте переменные окружения
- Для production используйте менеджеры секретов (HashiCorp Vault, AWS Secrets Manager)
- Ограничьте доступ к приватным ключам блокчейна

## 📈 Масштабирование

Для production-развертывания:

1. Используйте Docker для контейнеризации
2. Настройте мониторинг (Prometheus + Grafana)
3. Используйте распределенное хранилище для логов
4. Подключите реальный блокчейн (Ethereum, TON, Polygon)
