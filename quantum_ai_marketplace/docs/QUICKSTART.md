Для работы ИИ-агента загрузите модель Qwen2-7B:

```bash

mkdir -p models

# Скачайте модель с HuggingFace
git lfs install
git clone https://huggingface.co/Qwen/Qwen2-7B models/Qwen2-7B
```

Или используйте любую другую совместимую модель.

## 4. Запуск системы

### Базовый запуск

```bash
python main.py
```

Система запустится в режиме 24/7 с интервалом 1 час.

### Запуск без ИИ модели

Если модель не загружена, система будет работать в режиме бенчмарка:

```bash
python main.py
```

### Тестовый запуск (один цикл)

Отредактируйте `main.py` и измените интервал:

```python
INTERVAL_SECONDS = 10  # 10 секунд для теста
```

## ⚠️ Важные заметки

1. **Безопасность**: Не коммитьте файл `.env` в git!
2. **Модель**: Без модели ИИ система работает в режиме бенчмарка
3. **API лимиты**: VK API имеет ограничения на частоту запросов
4. **Ресурсы**: Квантовый бенчмарк может потреблять много CPU/RAM

## 🆘 Решение проблем

### Ошибка загрузки модели
```
❌ Ошибка загрузки модели: ...
```
**Решение**: Проверьте путь к модели или запустите без неё

### Ошибка VK API
```
❌ Ошибка публикации в VK: ...
```
**Решение**: Проверьте токен доступа в `.env`

### Нехватка памяти
```
MemoryError
```
**Решение**: Уменьшите `MAX_QUBITS` в настройках
